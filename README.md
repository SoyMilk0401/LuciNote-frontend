# LuciNote (루시노트)

**LuciNote**는 사용자의 문서를 효율적으로 관리하고, AI를 활용해 심도 있는 분석과 요약을 제공하는 **지능형 문서 관리 및 리서치 플랫폼**입니다. 단순한 파일 보관을 넘어, 문서를 학습하고 이해하여 연구와 업무의 생산성을 극대화합니다.

## 프로젝트 소개

이 프로젝트는 방대한 자료 속에서 핵심 정보를 빠르게 파악해야 하는 사용자들을 위해 기획되었습니다. 직관적인 인터페이스로 문서를 손쉽게 등록하고, 날짜별로 작업 내역을 관리할 수 있습니다. 특히 **'딥 리서치(Deep Research)'** 기능을 통해 사용자가 원하는 어조와 형식으로 문서를 요약하거나 분석할 수 있어, 리포트 작성이나 자료 조사 시간을 획기적으로 단축시켜 줍니다.

## 주요 기능

* **문서 관리**
    * 드래그 앤 드롭으로 간편하게 문서를 업로드하고 관리할 수 있습니다.
    * 등록된 문서는 체계적으로 보관되어 언제든 다시 열람할 수 있습니다.

* **딥 리서치 (Deep Research)**
    * **사용자 맞춤형 분석:** 단순 요약뿐만 아니라 '상세 요약', '간단 요약' 등 목적에 맞는 형식을 선택할 수 있습니다.
    * **어조 설정:** '설명하듯이' 혹은 '간략하게' 등 원하는 서술 방식을 지정하여 결과물을 생성합니다.
    * **확장된 검색 범위:** 분석 대상을 내부 문서로 한정하거나, 웹 검색까지 확장하여 더 풍부한 정보를 얻을 수 있습니다.

* **라이브러리 & 히스토리**
    * 작업한 결과물은 날짜별로 자동 분류되어 캘린더를 통해 쉽게 찾아볼 수 있습니다.
    * 과거의 분석 기록을 통해 연구 흐름을 한눈에 파악할 수 있습니다.

* **즐겨찾기**
    * 자주 사용하는 문서나 중요한 분석 결과는 즐겨찾기에 등록하여 빠르게 접근할 수 있습니다.
